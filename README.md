# 🍕 Pizza Sales & Orders Overview Dashboard (Excel-Based)
This Excel dashboard provides a comprehensive overview of pizza sales and order trends across different months, categories, sizes, and flavors. Designed for clear visual analytics, it empowers business decision-making through interactive charts and KPIs.

# 📈 Tools & Techniques Used
- Microsoft Excel (Dashboarding)

- Pivot Tables for data aggregation

- Pivot Charts (Bar, Line, Pie) for visual representation

- Slicers for interactivity (Month, Year, Pizza Size, etc.)

- Data Model integration for structured reporting

# 📊 Key Metrics (2022–2023)

- Total Pizzas Sold: 49,574

- Total Pizza Orders: 48,620
